# Webマンガサイト一覧 デザインドキュメント

[001_plan.md](./001_plan.md) で定義した Web サービスのビジュアルデザイン指針を定める。
UI 実装はこのドキュメントに従う。

## 1. デザインコンセプト

**「マンガ雑誌の目次」をメタファーにしたモノトーン UI。**

Web マンガサイトを紹介するディレクトリサービスであることを、原稿用紙のような白地と
墨のような黒い枠線で表現する。サイトカードといった UI 要素を
「コマ」に見立て、角張ったソリッドな輪郭とベタ塗りの影で構成する。

- 紙面（背景）は白、線とテキストは墨色の 2 色を基本とするモノトーン
- 主役はあくまで各サイトの情報（favicon・サービス名）。UI 自体は無彩色に徹し、
  各社の favicon が持つブランドカラーを引き立てる
- 過剰な漫画モチーフ（集中線・スクリーントーン・吹き出し等）は使わず、
  「太い枠線」「角張った輪郭」「ベタ塗りの影」の 3 要素に絞る

## 2. デザイン原則

| 原則             | 内容                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------- |
| 角張った輪郭     | `border-radius: 0` を基本とする。丸みは一切つけない（ファビコンのみ例外。3.1 章参照） |
| ソリッドな枠線   | UI 要素の輪郭は墨色の実線ボーダーで描く。淡い線やグラデーションは使わない             |
| ベタ塗りの影     | `box-shadow` は blur を使わず、右下方向へのオフセットのみのベタ塗りとする             |
| モノトーン基調   | 墨色 `#2e3142` と白 `#fff`、およびその中間グレーのみで構成する                        |
| 例外カラーの限定 | 有彩色の使用は「他社サービスのロゴ」「エラー表示」のみに限定する                      |

ベタ塗りの影の基本形:

```css
/* blur・spread を持たないオフセットシャドウ */
box-shadow: 4px 4px 0 0 var(--color-ink);
```

## 3. デザイントークン

トークンは CSS カスタムプロパティとしてグローバル CSS に定義する。

### 3.1 カラー

| トークン         | 値        | 用途                                         |
| ---------------- | --------- | -------------------------------------------- |
| `--color-ink`    | `#2e3142` | 枠線・本文テキスト・影・塗りつぶし背景       |
| `--color-bg`     | `#fff`    | ページ背景・コンポーネント背景               |
| `--color-ink-70` | `#6c6f7b` | サブテキスト（出版社名・補足）               |
| `--color-ink-40` | `#abadb3` | disabled 相当の状態（利用不可バッジ等）      |
| `--color-ink-15` | `#e0e0e3` | 区切り線・淡い枠線                           |
| `--color-ink-5`  | `#f5f5f6` | わずかな面の塗り分け（コードブロック背景等） |
| `--color-error`  | `#c73e3e` | エラーテキスト・エラー枠線（例外カラー）     |

- グレー段階は `--color-ink` と白の混色（`color-mix(in srgb, var(--color-ink) 70%, white)` 相当）。
  上表の hex はその計算結果を固定値化したもの
- 有彩色トークンは `--color-error` の 1 つに限定する
- 他社サービスのロゴ・ファビコンは各社のブランドカラーをそのまま表示する。
  モノトーン化（グレースケールフィルタ等）による改変は行わない
- ファビコンのみ、角丸なし原則の例外として `border-radius: 4px` を許容する
  （元画像が角丸で作られている場合になじませるため）

### 3.2 タイポグラフィ

Web フォントは読み込まず、システムフォントのみを使用する。

```css
--font-sans:
  system-ui, -apple-system, "Hiragino Sans", "Yu Gothic UI", "Yu Gothic",
  "Noto Sans JP", sans-serif;
```

| トークン    | サイズ | ウェイト | 用途                             |
| ----------- | ------ | -------- | --------------------------------- |
| `--text-xl` | 24px   | 700      | ページタイトル（サービスロゴ）   |
| `--text-lg` | 18px   | 700      | カードのサービス名               |
| `--text-md` | 15px   | 700      | セクション見出し                 |
| `--text-sm` | 13px   | 400      | 本文・出版社名・補足             |
| `--text-xs` | 11px   | 700      | 小さなラベル・バッジ             |

- 見出し・タイトル・バッジは太字（700）で「描き文字」のような強さを出す
- `line-height` は本文 1.7、見出し 1.4 を基本とする
- 実装では上表の各トークンをサイズ・ウェイト・行間・フォントファミリーをまとめた
  `font` ショートハンド（例: `--text-xl: 700 24px/1.4 var(--font-sans);`）として定義する

### 3.3 ボーダー・シャドウ・角丸

| トークン              | 値                             | 用途                                                         |
| --------------------- | ------------------------------- | ------------------------------------------------------------ |
| `--border-width`      | `2px`                          | 標準の枠線（カード）                                         |
| `--border-width-bold` | `3px`                          | 強調枠線（ヘッダー下線）                                     |
| `--radius`            | `0`                            | 全要素共通。角丸は使わない（ファビコンのみ例外。3.1 章参照） |
| `--shadow-sm`         | `4px 4px 0 0 var(--color-ink)` | カードの標準の影                                             |
| `--shadow-lg`         | `8px 8px 0 0 var(--color-ink)` | hover 時の浮き上がり                                         |

### 3.4 スペーシング

4px を基数としたスケールを使用する。

| トークン    | 値   |
| ----------- | ---- |
| `--space-1` | 4px  |
| `--space-2` | 8px  |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-6` | 24px |
| `--space-8` | 32px |

## 4. コンポーネント仕様

[001_plan.md の 6 章「画面仕様」](./001_plan.md) に登場する UI 要素を対象とする。

### 4.1 サイトカード

一覧の grid に並ぶ、1 掲載サイト = 1 コマのカード。

- 白背景、`--border-width` の墨色枠線、`--shadow-sm` の影
- 構成（上から順に）
  1. OGP画像: カード上辺いっぱいにブリードさせて表示する
     （アスペクト比 1200:630、`object-fit: cover`、角丸なし、
     下辺に `--border-width` の墨色ボーダー）
  2. ヘッダー行: favicon（`--text-lg` 相当のサイズ、角丸 4px の例外を適用）+
     サービス名（`--text-lg` 太字）+ 出版社名（`--text-sm`、`--color-ink-70`）
  3. メタ情報: 更新頻度・種別（`--text-sm`、`--color-ink-70`。ラベルは墨色太字）
  4. 説明文（`--text-sm`、`--color-ink-70`）
  5. 利用可否バッジ: 購入・レンタル・定期購読・アプリの 4 種を横並びで常時表示する。
     `--text-xs`、`padding: 2px 8px`、角丸なし。有効時は墨色枠線 + 墨色テキスト、
     無効時は `--color-ink-40` の dim スタイルで区別する
- カード全体がサイト詳細ページ（[4.3](#43-サイト詳細ページ)）へのリンク。
  ホバー時は影を `--shadow-lg` に拡大しつつ `translate(-2px, -2px)` して
  「コマが浮き上がる」動きをつける（`transition: 0.15s ease`）
- active（押下）時は逆に `translate(2px, 2px)` + 影を消し、紙面に沈む動きとする

### 4.2 ヘッダー / フッター

- ヘッダー: 白背景。下辺に `--border-width-bold` の墨色ボーダーを引き、
  紙面の枠線のように見せる。左にサービス名（`--text-xl` 太字テキストロゴ）
- フッター: 上辺に `--border-width` のボーダー。
  コピーライト・リポジトリへのリンク等を `--color-ink-70` で表示

### 4.3 サイト詳細ページ

サイトカードのような枠線・影の「コマ」フレームは持たず、ページ背景の上に
サイトの全属性を縦積みで表示するフラットなレイアウトとする。

- 構成（上から順に）
  1. OGP画像: 幅いっぱい、アスペクト比 1200:630、`object-fit: cover`、角丸なし。
     クリックで掲載サイトのトップページへ遷移する
  2. ヘッダー行: favicon + サービス名（`--text-xl` 太字）+ 出版社名
  3. メタ情報: 出版社・開発元（`null` の場合は非表示）・
     更新頻度・種別・ログイン可否／アカウント種別
  4. 説明文
  5. 利用可否バッジ（サイトカードと同一の見た目）
  6. 掲載サイトのトップページへの外部リンクボタン（枠線 + `--shadow-sm`、
     ホバー・active 時の浮き沈みはサイトカードと同じ動き）
- ページ上部に一覧へ戻るリンクを設置する

### 4.4 エラー・空状態表示

**エラー表示（例外カラー使用箇所）**

- サーバーとの通信に失敗した場合など: 白地 + `--color-error` の枠線 + `--color-error` のテキストのボックス
- 有彩色を使うのはこのエラー表示と他社ロゴのみ。それ以外での赤の流用は禁止
- 現状の実装は動的なサーバー通信を持たない完全な静的サイトのため、エラー表示を
  必要とする箇所はない。将来 API 通信を伴う機能を追加した際に用いるパターンとして定義する

**空状態表示（モノトーン）**

- 掲載サイト一覧が 0 件の場合など: 破線ボーダー（`2px dashed var(--color-ink-40)`）の
  「空のコマ」を中央に置き、`--color-ink-70` のテキストで案内を表示

### 4.5 検索フォーム

種別・利用可否・ログイン可否・ログイン種別・開発元・更新頻度を組み合わせて
絞り込む検索ページ（[6.6](./001_plan.md#66-検索ページsearch)）のフォーム UI。

- 白背景、`--border-width` の墨色枠線、`--shadow-sm` の影（サイトカードと同じ「コマ」の見た目）
- 条件軸ごとに `<fieldset>` + `<legend>` でグルーピングし、縦に積んで並べる
  （種別 / 利用可否 / ログイン可否 / ログイン種別 / 開発元 / 更新頻度）。
  `legend` は `--text-sm` 太字
- ログイン可否のみ真偽値の単一選択のためラジオボタン（指定なし／あり／なし）とし、
  その他の項目はすべて複数選択可能なチェックボックスとする
- ラジオボタンはネイティブの `<input type="radio">` をそのまま使用し、
  `accent-color: var(--color-ink)` でモノトーン基調に合わせる（円形は選択方式として
  意味を持つ形状のため、角丸禁止の対象外とする）
- チェックボックスはネイティブスタイルのままだと Chromium 系ブラウザの標準スタイルで
  わずかに角丸が付き、3.3 章の「角丸は使わない」原則に反するため、`appearance: none`
  で自前描画する
  - 16px 四方、`--border-width` の墨色枠線、角丸なし（`--radius`）の正方形
  - チェック時は背景を墨色で塗りつぶし、中央に `--color-bg` 色の
    チェックマーク（`border` を使った L 字を `rotate(45deg)` させた形）を重ねる。
    `transform: translate(-50%, -60%) rotate(45deg)` で正方形の中心に配置する
- 選択状態は URL のクエリパラメータと一致させる（サーバーサイドで
  `checked` 属性を決定する。JS によるクライアント側の状態管理は行わない）
- フォーム下部に絞り込みボタン（サイトカードと同系統のソリッドな塗り + 影）と、
  条件をクリアするリンクを併置する
- フォーム直下に現在の絞り込み件数を `--text-sm`、`--color-ink-70` で表示する

## 5. アクセシビリティ・留意点

- コントラスト比
  - `--color-ink` on `--color-bg`: 約 12.8:1（WCAG AAA 相当）
  - `--color-ink-70` on `--color-bg`: 約 5.0:1（AA を満たす）。本文・サブテキストに使用可
  - `--color-ink-40` はコントラスト不足のため、無効状態の表現に限定し、
    読ませるテキストには使わない
  - `--color-error` on `--color-bg`: 約 5.0:1（AA を満たす）
- フォーカスリング: `outline: 2px solid var(--color-ink); outline-offset: 2px;` で統一し、
  角張った矩形の outline で世界観を維持する。`outline: none` による無効化は禁止
- hover / active の浮き沈みアニメーションは `prefers-reduced-motion: reduce` 時に無効化する
- 利用可否バッジは色だけでなくラベルテキスト自体で状態が読み取れるようにする
